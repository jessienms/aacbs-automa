# 크고 작은 생물들 솔로 봇

아그리콜라: 크고 작은 생물들(빅박스)을 위한 웹 앱입니다. 처음 화면에서 두 가지 중 하나를 고릅니다.

- **오토마와 솔로 플레이**: 혼자 플레이할 때 봇이 일꾼을 놓습니다.
- **멀티플레이 점수 계산**: 여럿이 플레이한 뒤 플레이어별 점수와 승자를 계산합니다.

솔로 모드는
`ref/bgg443176.pdf`의 Sam Carpenter 솔로 변형 v1.1 규칙을 구현했습니다.

## 사용법

웹 주소: https://jessienms.github.io/aacbs-automa/

`index.html`을 브라우저로 직접 열어도 됩니다 (빌드나 서버 불필요).

1. 난이도(쉬움 / 보통 / 어려움 / 팜마겟돈)를 고릅니다. 기본 특수 건물 4개는 항상 포함되고, 추가 특수 건물을 0–8개 드롭다운에서 고릅니다. 점수는 룰북 기준으로 자동 입력됩니다.
2. 룰북의 실제 게임판 이미지 위에 칸마다 쌓인 자원 수가 표시됩니다. 칸이나 건물 타일을 누르면 가져올 양을 보여주고, 확인하면 일꾼이 놓입니다. 봇은 고를 수 있는 선택지 중 하나를 무작위로 고르고, 공동 창고로 돌려놓을 물건을 알려줍니다.
3. 일꾼 6개를 모두 놓으면 번식을 마친 뒤 라운드를 끝냅니다. 보충 단계(누적 물건)는 앱이 계산합니다.
4. 건물 타일을 누르면 룰북의 건물 설명(비용, 점수, 효과)을 볼 수 있습니다.
5. 8라운드가 끝나면 봇 점수가 계산되고, 점수표에서 내 농장 상태를 고르면 내 점수와 승패가 바로 계산됩니다.

진행 상황은 브라우저에 자동 저장되며, 되돌리기를 지원합니다.

## 멀티플레이 점수 계산

- 2~4명(기본 게임은 2인)의 이름을 정하고, 플레이어별로 가축 수, 다 채운 확장판, 축사·외양간, 지은 건물을 고르면 점수가 계산됩니다.
- 건물은 한 사람만 지을 수 있으므로, 한 플레이어가 고른 건물은 다른 플레이어의 목록에서 빠집니다.
- * 건물은 조건(예: 아랫줄 건물 수)을 고르면 점수가 계산됩니다.
- 동점이면 룰북 8쪽대로 1라운드 시작 플레이어가 아니었던 사람이 이깁니다 (설정에서 시작 플레이어 선택).
- 휴대폰에서는 플레이어 탭으로 전환하고, 넓은 화면에서는 나란히 보입니다. 입력은 브라우저에 저장됩니다.

## 원문에 없어 앱에서 정한 부분

- 봇은 D20 대신(번호 없이) 고를 수 있는 선택지 중 하나를 무작위로 고릅니다. 빈 행동 칸 하나하나와, 특수 건물 짓기 자리가 비어 있으면 남은 건물 하나하나가 선택지입니다 (건물 수에 상관없음).
- 기본 특수 건물도 봇이 수집할 수 있습니다.
- 조건에 따라 점수가 달라지는 * 건물(저장고, 저택, 사무실, 확장터, 소·돼지 축사, 대농장, 사료 저장고, 통나무 집, 돌 조각소)은 봇에게 0점입니다. 내 점수표에서는 조건(예: 아랫줄 건물 수)을 고르면 점수가 계산되고, 소·돼지 축사는 가축 수로 자동 계산됩니다.

게임판 이미지(`img/board.jpg`)는 `ref/view.pdf` 6–7쪽에 들어 있는 게임판 원본 이미지를 그대로 꺼낸 것이고, 건물 타일 이미지(`img/tiles/`)는 9–12쪽에서 잘라낸 것, 자원 아이콘(`img/res/`)은 룰북 2·3·5쪽의 구성물 사진을 꺼낸 것입니다.
